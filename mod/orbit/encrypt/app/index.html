WHAT THIS IS

      
An encrypted message vault that ships no cipher of its own. You bring the circuit; the
      module runs it and keeps the ciphertext.

      
    
        
  1. Bring a circuit — a python file with encrypt/decrypt.
            It is validated by a roundtrip in a sandbox: no network, dropped privileges,
            cpu/memory limits, no filesystem writes.
    2. 
        
  2. Encrypt — the plaintext is passed to your circuit server-side. The ciphertext
            is uploaded to the store mod with your own protocol token and comes back as a CID.
    3. 
        
  3. Keys are never persisted. They live for one request. Nothing in the index can
            decrypt anything — it holds a CID, a circuit id and a label.
    4. 
        
  4. Take it back. Circuits and ciphertext both download. Delete removes the store
            object and the row; burn-after-read does it for you on first open.
    5. 
      

      
Want the server never to see the plaintext at all? Encrypt locally, upload to
      the store yourself, and register the CID with POST /messages/attach.
