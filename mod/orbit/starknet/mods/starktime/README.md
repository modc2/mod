# starknet.starktime — StarkTime

Lock STRK for longer, earn more. Weight = amount x lock multiplier (1x flexible up to 6x at four years); rewards stream every second.

An app on Starknet, listed in the starknet **Apps** tab. Its UI is the `starktime` mod's own app (`orbit/starktime`); this submod is its card on Starknet.

- address: `/starknet/apps/starktime/`
- fns: `facts`  ->  `GET /starknet/_api/apps/starktime/<fn>`  or  `m starknet.starktime/<fn>`
- `facts()` is what the Apps card shows.
