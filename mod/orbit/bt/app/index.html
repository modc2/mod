Open. As in actually open.

  
Taostats and tao.app sit on closed indexers you can't run, read, or fork. This explorer's entire stack — the indexer, the API, the MCP server, this page — is one open-source module you can run on a laptop.

  

    

      
The code

      
Everything lives in orbit/bt of the mod repo — the SQLite indexer is ~250 lines you can actually read.

      
github.com/modc2/mod → orbit/bt

    

    

      
The data

      
Every number on this page comes from a public endpoint — same table, no key, no rate-limit tiers:

      
curl …

    

    

      
The indexer

      
A background thread snapshots every subnet pool on an interval into local SQLite — that's the whole trick. Prices, changes, volume and charts are served from your own disk in microseconds.

The agent surface

      
The same registry drives an MCP server, so Claude — or any agent — gets the whole explorer and trading as tools. Closed explorers stop at a dashboard; this one is programmable.

MCP.

  
Wire the whole protocol into Claude — or any MCP client — in one line.

  

    

      
stdio recommended

      
Local, no server needed. From Claude Code:

      
claude mcp add bittensor -- python3 -m bt.mcp_server

      
Or in any mcpServers config:

      
{
  "bittensor": {
    "command": "python3",
    "args": ["-m", "bt.mcp_server"],
    "cwd": "/root/mod/mod/orbit/bt"
  }
}

    

    

      
Streamable HTTP

      
This server also speaks MCP over HTTP — point a remote client at:

      
…/mcp

      
Same tools, same schemas. Try it:

      
curl -s …/mcp -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
