About

Store, test, and run commands against SSH targets — gated by your wallet. Two auth backends are supported:

  • MetaMask (Ethereum personal_sign)
  • SubWallet / Polkadot.js (sr25519, SS58 prefix 42 — Bittensor)

Credentials live in a key vault: named passwords / private keys, encrypted in the browser with AES-GCM under a key derived from a vault passphrase that never leaves this page. The server only ever stores ciphertext — not the passphrase, not anything that can derive it.
