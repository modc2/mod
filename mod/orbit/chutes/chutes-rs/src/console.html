▶ KEY VAULTtwo places a key can live

THIS BOX writes ~/.mod/chutes/api_key on the server — the key the MCP server, the stdio transport, the m CLI and every browser without its own key all share. Only the box's owner may set or remove it: sign in with a wallet (one personal_sign, no transaction) or paste a token minted on the box with m chutes/token. The key is checked against chutes.ai before it lands on disk, and is never echoed back. THIS BROWSER keeps a key in localStorage instead and sends it as an x-chutes-key header — it wins over the box key for your own requests. Resolution: explicit → CHUTES_API_KEY → api_key → key.json → ~/.mod/model/chutes/apikeys.json; /status reports which. ~/.mod/chutes/defaults.json names the default chute and its stand-ins.
