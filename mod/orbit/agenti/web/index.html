Give your AI agent a wallet.

Your agent gets its own crypto wallet so it can pay for APIs by itself (x402, in USDC), get paid, and check its balance. You set the spending limits.

Get started

1
Create a wallet
One wallet gives your agent an address on Base, Ethereum, Arbitrum, Polygon and Solana.
2
Add some USDC
Send a few dollars of USDC on Base to the wallet. Paid APIs usually cost a cent or less per call. Show my address
3
Try a paid API
Find one, see its price, and pay for a single call. Open PAY
4
Hand it to your agent
Connect Claude or any MCP client to this node so the agent can pay inside your limits. How to connect
