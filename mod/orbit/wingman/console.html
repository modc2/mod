audit

Everything a program can check about a profile photo, and nothing it cannot. Each issue costs points and says why; bad disqualifies a photo from leading. Expression, eye contact, outfit and setting are not scored — no number here claims to know them.

lineup

The best N in the order they should go up. A sharp, lit solo face leads (12–55% of the frame); then variety — portrait, full-body, headshot, a wider shot; near-duplicates collapse to the sharper one; a group shot goes after slot 3 and at most once. gaps is the honest part: what the set lacks that no edit adds.

render

A face-aware crop to the app's card ratio — eyes about 40% down, headroom kept, re-centred when there is room — resized to the card, then a gentle polish: autocontrast, an exposure lift only when the frame is dark, a hair of colour, a light sharpen. The JPEG is written with no EXIF, no GPS, no colour profile, no thumbnail. No skin is smoothed and no background is replaced.

export

Lineup → renders for one app → a zip in slot order (01-…, 02-…) with report.json explaining every choice. Upload them in that order.

mcp

Twelve tools on POST /mcp, the same handlers the buttons on this page call. Point an agent at it and it can do everything here, including telling you what the set is missing.
