# zkworld docs

| page | for | what's in it |
|------|-----|--------------|
| [getting-started.md](getting-started.md) | anyone | what this is, plain words, first five minutes |
| [simple-apps.md](simple-apps.md) | whoever builds a contract | hiding inputs and outputs, friendly labels, visuals: the `app.json` reference |
| [../README.md](../README.md) | programmers | every function, the toolchain, the API, the layout |

The short version: every contract you make here gets a web page at
`/zkworld/<name>/`. That page has two views, **Simple** and **Developer**.
Simple is what you show people. A small `app.json` file next to the contract
controls what Simple shows.
