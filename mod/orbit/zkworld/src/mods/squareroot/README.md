# squareroot

Prove you know a square root of a public number without revealing it.

A Noir project mod (framework `noir`, submod of `zkworld`), addressed `zkworld.squareroot`. `Nargo.toml` is its manifest; build and test go through the zkworld noir adapter.

```sh
m zkworld.squareroot/build
m zkworld.squareroot/test
m zkworld.squareroot/vibe prompt="..."
```
