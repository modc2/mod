# factors_noir

FactorsNoir — a Noir project.

A Noir project mod (framework `noir`, submod of `zkworld`), addressed `zkworld.factors_noir`. `Nargo.toml` is its manifest; build and test go through the zkworld noir adapter.

```sh
m zkworld.factors_noir/build
m zkworld.factors_noir/test
m zkworld.factors_noir/vibe prompt="..."
```
