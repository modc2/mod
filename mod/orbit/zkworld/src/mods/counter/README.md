# counter

Counter — a felt252 get/set example contract.

A Cairo contract mod (submod of `zkworld`), addressed `zkworld.counter`. A self-contained Scarb project: `src/lib.cairo` is the contract, `tests/` the snforge tests.

```sh
m zkworld.counter/build
m zkworld.counter/test
m zkworld.counter/vibe prompt="..."
```
