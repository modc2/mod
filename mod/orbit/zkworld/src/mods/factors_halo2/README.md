# factors_halo2

FactorsHalo2 — a Rust project.

A Rust project mod (framework `halo2`, submod of `zkworld`), addressed `zkworld.factors_halo2`. `Cargo.toml` is its manifest; build and test go through the zkworld halo2 adapter.

```sh
m zkworld.factors_halo2/build
m zkworld.factors_halo2/test
m zkworld.factors_halo2/vibe prompt="..."
```
