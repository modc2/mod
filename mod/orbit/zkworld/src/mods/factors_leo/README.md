# factors_leo

FactorsLeo — a Leo project.

A Leo project mod (framework `leo`, submod of `zkworld`), addressed `zkworld.factors_leo`. `program.json` is its manifest; build and test go through the zkworld leo adapter.

```sh
m zkworld.factors_leo/build
m zkworld.factors_leo/test
m zkworld.factors_leo/vibe prompt="..."
```
