# factors_gnark

FactorsGnark — a Go project.

A Go project mod (framework `gnark`, submod of `zkworld`), addressed `zkworld.factors_gnark`. `go.mod` is its manifest; build and test go through the zkworld gnark adapter.

```sh
m zkworld.factors_gnark/build
m zkworld.factors_gnark/test
m zkworld.factors_gnark/vibe prompt="..."
```
