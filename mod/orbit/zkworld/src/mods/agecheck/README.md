# agecheck

Prove you are old enough without saying your age.

A Circom 2 project mod (framework `circom`, submod of `zkworld`), addressed `zkworld.agecheck`. `main.circom` is its manifest; build and test go through the zkworld circom adapter.

```sh
m zkworld.agecheck/build
m zkworld.agecheck/test
m zkworld.agecheck/vibe prompt="..."
```
