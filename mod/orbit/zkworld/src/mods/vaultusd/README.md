# vaultusd

A crypto-backed digital dollar

A Cairo contract mod (submod of `zkworld`), addressed `zkworld.vaultusd`. A self-contained Scarb project: `src/lib.cairo` is the contract, `tests/` the snforge tests.

```sh
m zkworld.vaultusd/build
m zkworld.vaultusd/test
m zkworld.vaultusd/vibe prompt="..."
```
