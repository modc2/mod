# factors_zok

FactorsZok — a ZoKrates DSL project.

A ZoKrates DSL project mod (framework `zokrates`, submod of `zkworld`), addressed `zkworld.factors_zok`. `main.zok` is its manifest; build and test go through the zkworld zokrates adapter.

```sh
m zkworld.factors_zok/build
m zkworld.factors_zok/test
m zkworld.factors_zok/vibe prompt="..."
```
