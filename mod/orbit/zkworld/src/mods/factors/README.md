# factors

Factors — a Circom 2 project.

A Circom 2 project mod (framework `circom`, submod of `zkworld`), addressed `zkworld.factors`. `main.circom` is its manifest; build and test go through the zkworld circom adapter.

```sh
m zkworld.factors/build
m zkworld.factors/test
m zkworld.factors/vibe prompt="..."
```
