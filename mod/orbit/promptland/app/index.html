Sign in with a wallet

Same flow as the Build console: the server hands you a one-time challenge, your key signs it, a verified signature opens your session. The first wallet ever to sign in claims ownership of this instance. Your prompt library is private to your address; sharing publishes a prompt to the public gallery as a localfs CID.

⟠ Browser wallet

MetaMask or any injected EVM wallet. The extension pops up to sign the challenge — keys never leave it.

▤ Local wallet

A wallet generated in this browser and kept in localStorage (promptland_seed). Created on first use, reused after — no extension needed.

✳ Password key

Deterministic key derived from a password (keccak256). The same password is the same identity on any device.
