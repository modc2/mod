zkapi

pay for APIs from an Ethereum deposit, without the server learning which deposit is yours

How it works

Deposit ETH into the zkAPI vault once. Each request carries a Groth16 proof that some deposit in the vault can cover it, so the server issues a short-lived, spend-capped API key without learning which deposit paid. After the call, the server signs your new balance. You can withdraw the rest at any time, and you can still get it out even if the server stops cooperating. This module runs the official zkAPI stack (): the vault and verifier contracts, zkapi serverd, the indexer, the challenger and the production wallet core. It runs them on a local devnet, and it checks the live Ethereum deployments against their pinned values.
